# Farid Bagheri — Personal Website

Static personal research portfolio and blog for GitHub Pages.

## Publish

This repository is intended to live at:

`https://github.com/faridbagheri/faridbagheri.github.io`

For a GitHub user site, keep `index.html` at the repository root. In GitHub, open **Settings → Pages** and deploy from the `main` branch / root folder if Pages is not already enabled.

## Structure

- `index.html` — portfolio homepage
- `styles.css` — responsive visual design
- `script.js` — theme toggle and mobile navigation
- `blog/` — research notes
- `assets/Farid-Bagheri-CV.pdf` — downloadable CV

## Editing

All content is plain HTML/CSS/JavaScript, so no build step is required.
